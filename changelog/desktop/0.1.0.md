# SumVue 0.1.0

## 新功能

- 推出 SumVue 视频笔记工作流：导入视频链接、下载视频、本地转录，并根据文稿和镜头画面生成 AI 总结。
- 本地转录后按句子建立镜头和画面帧；总结展示摘要、章节、亮点、思考与精选画面帧，并可从文稿或精选画面定位播放器。
- 增加 B 站账号登录与收藏夹页面。收藏视频按分组同步到本地数据库，支持封面、收藏时间、分页、单个下载和批量下载。
- 发现新增收藏视频后，可一键加入“下载 → 本地转录 → AI 总结”任务流程；项目空间中的 B 站视频归入“B 站收藏夹”目录。

## 界面与体验

- 精简文稿布局，隐藏停顿、时间和说话人标记；文稿与 AI 总结在同一滚动区域中切换定位。
- 整理 B 站收藏夹工具栏、分页及下载操作，保留原有中间任务面板。
- 将桌面应用、CLI 和相关界面标识更新为 SumVue。
