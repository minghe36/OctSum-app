# V0.6.0

- 命令行工具与浏览器扩展正式发布
- 支持点击视频详情中的标题打开原始视频页面。
- 视频没有音轨或音频格式暂不支持播放时，播放器会给出提示，并支持复制诊断信息。
- 修复长视频转录时极短片段对齐失败导致整条任务中断的问题。遇到无法对齐的片段，会保留该片段原有的文字和时间。
- 官方 AI 总结和在线字幕翻译的默认模型调整为 GPT-6 Luna。已保存且仍受支持的模型选择继续生效。
- 修复 B 站收藏夹中有已删除或地区受限视频时，部分可用收藏无法同步的问题。优化 YouTube 收藏同步，刷新列表期间保留已加载的视频。
- 在「设置 → 基础设置」新增重复项目空间一键修复。同一路径的重复登记会被归档，保留最近更新的一条。修复后重启应用生效。
- 启动时清理文件已不存在的本地视频缓存记录，跳过当前不可访问的空间。
