# V0.2.1

- 优化本地转录引擎的数据传输与并行处理，提升转录和时间轴对齐效率，转录速度提升 50%。
- Qwen3-ASR-1.7B 升级为浩叔优化版，转录速度提升 60%。
- 优化远程转录的音频分段处理，并精简任务花费展示。
- 优化字幕翻译的分批处理，全部批次完成后统一保存结果。
- 新工作区使用 `.octsum` 数据目录。
- 视频播放器新增当前画面截图和原视频链接入口，优化全屏下的设置操作。
- 支持配置视频下载分辨率上限，并在下载前确认。
- 优化共享 AI 结果复用，减少重复处理。
- 优化 OctSum CLI 安装、路径配置与启动兼容性，支持从应用导出配套 Agent Skill。
- 优化激活状态检查与相关提示。
- 修复转录后视频字幕未自动显示、需要调整样式才显示的问题。
- 修复交给 AI Agent 总结或翻译后，关闭窗口或切换页面导致自动同步中断的问题。
- 修复 Agent 结果因字幕置信度的浮点精度变化被误判为无效的问题。
- 完善 Agent 翻译结果自动导入与字幕刷新，继续校验目标语言及字幕 ID 的完整性和顺序。
- 优化模型下载的并发与分段传输，提高下载效率。
- 向量模型所需文件支持并行下载，各文件独立显示下载进度。
- 修复下载配套模型时，提示中的文件名和进度未及时切换的问题。
- 优化转录设置自动保存，本地和远程设置修改后直接生效，减少重复操作与成功提示。
- 设置页新增独立的 CLI 配置入口，方便安装和管理命令行工具。
- 优化向量模型安装引导与提示文案。
- 精简任务队列展示，调整下载提示按钮的对齐方式。
