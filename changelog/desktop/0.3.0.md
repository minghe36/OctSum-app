# V0.3.0

- 优化一键总结与收藏夹处理流程，直接使用已保存的转录和总结设置，减少重复选择。
- 新用户默认使用在线转录，保留已有的本地转录选择；在线转录默认自动识别语言。
- 完善远程转录的默认配置、音频分片检测和完成提醒。
- 修复 B 站收藏夹视频下载到默认目录的问题，按对应收藏夹名称保存到“B 站收藏夹”目录。
- 高亮片段导出新增“合并成一个视频”开关，默认分别导出，开启后按时间顺序合成为一个视频。
- 修复应用 AI 总结中的字幕纠错后，已有总结无法复用的问题。
- 修复搜索结果点击后正文高亮位置不准确的问题，正确高亮对应的搜索关键词。
- 修复总结和关键帧任务的开始提示延迟，以及完成后重复出现开始提示的问题。
- 完善任务消耗金额与节省金额展示，金额暂不可用时仍保留对应字段。
- 自定义 API 端点不再显示官网模型的优惠标签；任务中标明“自定义的 API 端点”，金额显示“暂无”。
- 修复任务统计中直接显示内部任务名称的问题，补齐相关导出任务的中英文文案。
- 精简总结复用弹窗，仅保留预估节省金额；移除总结和关键帧任务开始提示中的说明文字。
- 隐藏模型用量看板顶部的供应商选择框，默认展示官网用量数据。
- 将项目空间默认上限调整为 200 GB，保留用户已保存的自定义上限。
- 更新新人引导的演示视频，改用新的 B 站视频链接。
