# V0.5.1

- 统一各平台视频下载的登录异常提示：Cookie 读取、解密失败或登录信息缺失时，引导到设置登录平台账号，登录完成后重试。
- 移除任务队列中的“如何解决”入口，保留“点此设置”，简化登录异常处理流程。
- 修复任务重试后仍显示上一次登录异常的问题，重新排队、恢复执行及完成时清除旧错误提示。
- 优化任务列表“重试”按钮的点击区域与鼠标反馈，支持点击图标、文字及整个按钮触发重试。
- 新增抖音、快手视频链接及分享文本解析，支持从包含说明文字的分享内容中提取链接并提交任务。
- 新增小宇宙单集下载，支持音频及带视频的节目；播放与下载使用已保存的小宇宙扫码登录会话。
- 完善小红书短链接及多平台分享文本识别，统一首页、CLI 和浏览器提交的视频来源解析流程。
- 新增并完善平台扫码登录，B 站登录改用统一的平台登录弹窗，减少不同入口之间的操作差异。
- YouTube 列表改用本机浏览器或 Cookie 文件连接，读取真实账号和播放列表；
- 更新内置 yt-dlp，完善快手媒体信息读取与 TS 转 MP4 无损封装，提高下载与播放兼容性
- 新增小宇宙收藏和快手收藏页面，支持搜索、分页、单项处理与批量下载、转录、总结。
- 收藏按工作区和账号隔离保存。完整同步成功后更新本地数据，同步失败时保留已有收藏，避免把请求失败显示为空列表。
- 优化 B 站收藏成员同步与已失效分组的选择恢复，减少远程收藏变化后列表残留或选中项失效的问题。
- YouTube 将自建播放列表、我赞过的视频和稍后观看分别展示，支持按各自列表同步与处理。
- 调整 YouTube 页面布局：收藏优先排列，顶部卡片常驻，默认在下方展示收藏视频；点击卡片切换列表，当前选中卡片使用浅灰色背景。
- YouTube 优先读取已保存的本地账号，避免每次进入都通过 yt-dlp 重新识别账号并阻塞页面。
- YouTube、小宇宙和快手在应用运行期间保留账号与列表缓存，返回页面时直接展示已有内容，再后台同步；重启后仍可读取持久化收藏。
- 小宇宙和快手优先使用已保存的账号身份，不再仅因缺少昵称而等待远程请求；手动同步及登录、退出后的缓存更新继续生效。
- 统一 B 站、小宇宙和快手的页面标题区、工具栏、登录入口与分页体验，优化 YouTube 列表操作和下载设置入口。
- 打开或同步收藏只更新列表，不会自动下载、转录或总结；
- 新增 Index-Translate-2B 本地翻译模型，可在字幕翻译弹窗中关闭远程模型翻译，使用本机模型完成翻译。
- 显著提升模型下载速度
- 支持单文件与批量字幕翻译，本地翻译支持暂停和取消
- 实现逐字字幕动画
- 修正长视频播放卡顿问题
- AI 总结扩展 AI 总结的供应商选择，支持使用已配置的自定义模型供应商
- 将总结中的问题栏目调整为“深入问 AI”，生成最多 5 个基于视频内容、可独立提问的延伸问题；历史结果展示与导出也限制为最多 5 个。
- 移除“金句”栏目的生成选项、导航、展示和 Markdown 导出，已有历史数据保留兼容读取。
- 新增章节悬浮目录，显示章节数量、标题和时间，可点击跳转播放，并支持键盘操作。
- 修复总结选中文字后的快捷键复制，优化文稿、总结及阅读设置中的文字颜色和深色主题可读性。
- 应用启动时，将上次遗留的待执行下载、转录、总结和媒体工作流任务暂停，等待手动恢复，避免启动后自动开始处理。
- 中断的下载和本地转录保留任务参数与进度；中断的远程请求沿用失败后重试机制，减少重复发起结果不确定的请求。
- 本地翻译使用独立的本地计算调度类别，不占用远程 AI 并发名额。
- 新增本地翻译节省估算，并计入软件累计本地节省；金额依据模型价格与估算文本量计算，价格缺失时不显示虚构数值。
- 完善外部供应商任务、完整缓存命中和部分缓存复用的费用识别，减少零花费、节省金额与实际账单混淆。
- 自定义端点的实际调用任务显示“消耗金额：-”及调用供应商名称，不再展示不可用的金额和节省金额。
- 修复视频封面缺失及旧视频封面恢复，优先展示平台封面，并使用本地封面作为回退。
- 首页和目录视频卡片完整展示不同比例的封面，避免大图撑开布局或被裁切；封面不再误用分析关键帧。
- 优化暂停预览时的本地图片复用，并在媒体文件替换后刷新过期的时长信息。
- 修复工作区选择恢复，改善重新打开应用后的工作区使用体验。
- 优化模型下载源配置、签名链接获取和原生传输，支持并发分段下载、暂停续传、进度与速度显示，以及远程文件版本校验。
- 完善 Windows 开发环境与资源打包处理，以及发布平台保留、依赖资源和上传产物检查。
- 【浏览器插件】在 B 站视频页面增加处理入口，在 YouTube 播放页面增加总结按钮，可直接提交到桌面端。
- 【浏览器插件】完善浏览器页面任务的持续跟踪、状态通知和重复请求识别，提交后可继续查看处理进度。
- 【浏览器插件】完善扩展与客户端断开、提交等待超时、缺少模型配置等情况的反馈，以及 Cookie 连接失败时的恢复指引。
- 【浏览器插件】支持独立打包 Chrome / Edge 插件，桌面端复用插件资源，完善扩展下载、原生通信与 macOS 资源签名处理。
- 修复长视频播放卡顿：移除文稿逐词、逐句无用途的行内定位层及颜色过渡，避免 WebKit 在播放高亮时反复重建大量文字交互区域。
